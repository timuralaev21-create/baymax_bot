# Baymax Ready — улучшенная версия

## Что добавлено

- Расчёт здоровья: вес, рост, тип формы, BMI, ориентир КБЖУ, вода.
- Счётчик воды: +250 мл и сброс.
- Напоминания: точное время `18:30`, относительное время `через 20 минут`, `через 2 часа`, `через 3 дня`.
- План дня: хранится только на текущий день и очищается при новом дне.
- Цели: хранятся постоянно, можно добавлять и удалять.
- Пульс дня: энергия, настроение, сон; утром в 08:00 бот просит пройти пульс.
- Учёба: объяснение темы и задачи на время.
- Ментальная поддержка: спокойные безопасные ответы.
- Физическое здоровье: безопасные рекомендации без опасных назначений.
- Геопозиция: ссылки на ближайшие аптеки через Google Maps, 2GIS, Yandex Maps.
- Профиль и леденцы: 1 леденец за активность раз в день.
- Магазин статусов: `/shop`.
- Админка: `/admin`, `/broadcast текст` для админов из `.env`.
- Команды для всех основных кнопок.

## Важное про время пользователя

Telegram Bot API не передаёт IP пользователя. Поэтому невозможно честно определить часовой пояс по IP внутри Telegram-бота. В этой версии используется время сервера/проекта. Для Узбекистана ставь сервер или hosting timezone на `Asia/Tashkent`, либо расширь профиль пользователя выбором часового пояса.

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

`.env` должен содержать:

```env
BOT_TOKEN=токен_бота
ADMINS=123456789,987654321
DEFAULT_HEIGHT=175
DEFAULT_WEIGHT=89
DEFAULT_TIMEZONE_OFFSET=5
```

## Команды

- `/start` — запуск
- `/menu` — главное меню
- `/help` — помощь
- `/profile` — профиль
- `/health` — здоровье
- `/norm` — расчёт нормы
- `/water` — +250 мл воды
- `/resetwater` — сброс воды
- `/steps` — добавить шаги
- `/mental` — ментальная поддержка
- `/physical` — физическое здоровье
- `/reminders` — напоминания
- `/addreminder` — добавить напоминание
- `/myreminders` — список напоминаний
- `/day` — план и цели
- `/plan` — план на сегодня
- `/goals` — цели
- `/pulse` — пульс дня
- `/study` — учёба
- `/explain` — объяснить тему
- `/timer` — задачи на время
- `/shop` — магазин статусов
- `/admin` — админ-панель
- `/broadcast текст` — рассылка
